# Hermes Face · v0.1

Первая живая форма в существующем Hermes Cube. Одна симуляция частиц — разные оболочки; память, чат, настройки и старые формы не удаляются.

## Запуск на Mac

`./Hermes\ Face.command` в Terminal или двойной клик по файлу `.command`. Использует проектный `venv` с numpy/Pillow/moderngl. На macOS по умолчанию включён непрозрачный фон для надёжной видимости (`HERMES_MAC_OPAQUE=1`); прозрачный экспериментальный режим запускается `HERMES_MAC_OPAQUE=0 ./Hermes\ Face.command`.

Если программа уже запущена, второй экземпляр не нужен. Перезапускайте её через выход из текущего экземпляра.

## Управление

- **F**: открыть необязательную панель Hermes Face
- **1 / 2 / 3 / 4**: Holographic / Bioform / Retro Hacker / Glass
- **Двойной клик по персонажу**: реакция и фраза «Я здесь»
- **C**: окно чата, **S**: расширенные настройки, **T**: перемещение, **R**: трейлы
- В панели Face можно вернуть «Облако» или «Куб» без удаления новой формы

## Архитектура

- `core/face_avatar.py` — детерминированные 3D-координаты головы, тела, глаз, рта, антенн
- `core/face_themes.py` — четыре безопасных цветовых пресета
- `core/systems/grid_generator.py` — кэш формы `face`
- `core/systems/color.py` — применение пресета с сохранением режима текста
- `core/systems/rotation.py` — мягкие повороты лица вместо непрерывного вращения
- `main.py` — локальная панель Face, жест реакции, комбинации клавиш

**Важно:** это первой версии анимированный персонаж, не автономный разум. Объекты «моды» и «хаки» пока концепция будущего менеджера расширений. Настоящий код модификаций не исполняется. 1K — верхний предел размеров окна/FBO, а не принудительная отрисовка в 1024 px.
