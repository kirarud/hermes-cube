# Hermes Face · Calm Orb (спокойный персонаж)

Новый облик по умолчанию для формы `face`: небольшой округлый светящийся талисман вместо похожего на человека силуэта.

## Зачем изменили дизайн

Предыдущая версия напоминала живое существо с пустыми кольцевыми глазами, постоянной улыбкой, длинными антеннами и тёмным фоном. Новый вариант делает выражение визуально спокойнее: одна округлая форма без шеи, заполненные глаза с мягкими зрачками, короткая нейтральная линия рта и небольшие щёчные акценты. Улыбка появляется только в состоянии `happy`. Фоновая среда на macOS в непрозрачном режиме окрашена в приглушённый сине-серый цвет.

## Использование

- Запускай Hermes Face обычным способом.
- Нажми **F** → выбери форму **Добрый** и тему **Soft Glow**.
- **Архивный облик** — отдельная кнопка «Старый экспериментальный облик (архив)» в том же меню.
- Другие формы `cloud` и `cube` остались.
- В расширенных настройках форма старого персонажа называется `face_original`.
- В локальном API: `POST /api/entity` с `{"action":"shape","value":"face"}` или `{"action":"skin","value":"Soft Glow"}`.

## Что сохранено

Старый генератор `core/face_avatar.py` не менялся. Точный прежний силуэт доступен в `shape_cache['face_original']`. Новый вариант — `core/friendly_face.py`. Оба используют то же количество частиц и тот же рендерер, без внешних моделей и новых зависимостей.

## Проверка

`HERMES_LOCKED=1 ./venv/bin/python -m unittest discover -s tests -p 'test_*.py' -q`

При запущенном локальном Hermes флаг `HERMES_LOCKED=1` необходим для тестов, импортирующих `cube_app`, поскольку приложение имеет защиту от нескольких экземпляров.
