# Hermes Entity Control · Alpha 0.2

Первый модуль управления сущностью на основе **существующего Hermes Cube**, без создания нового рендерера. Это расширение Hermes Face v0.1, а не его замена.

## Что работает

- Единый контракт команд `core/entity_controller.py` для форм, скинов, настроения и направления взгляда.
- Общий `World`: память, AI, частицы и история диалога не пересоздаются при смене формы.
- Формы `face`, `cloud` и `cube`; четыре существующих скина Hermes Face.
- В меню **F → ПОВОРОТ** появился виртуальный джойстик. Перетаскивайте его мышью: поворот реально применяется в `core/systems/rotation.py` с плавным сглаживанием. Отпустите — персонаж вернётся к обычной анимации.
- Локальный API `POST /api/entity`: команды ставятся в ограниченную очередь и исполняются только в потоке Tk.
- `GET /api/status` возвращает `entity` с формой, скином, настроением и положением джойстика.

## Команды для локального теста

Запустите приложение штатным `./Hermes\ Face.command` (только если оно ещё не запущено). Затем в другом терминале:

```bash
curl -sS http://127.0.0.1:8081/api/status
curl -sS -X POST http://127.0.0.1:8081/api/entity -H 'Content-Type: application/json' -d '{"action":"shape","value":"face"}'
curl -sS -X POST http://127.0.0.1:8081/api/entity -H 'Content-Type: application/json' -d '{"action":"skin","value":"Bioform"}'
curl -sS -X POST http://127.0.0.1:8081/api/entity -H 'Content-Type: application/json' -d '{"action":"look","x":0.6,"y":0.25}'
curl -sS -X POST http://127.0.0.1:8081/api/entity -H 'Content-Type: application/json' -d '{"action":"look","x":0,"y":0}'
curl -sS -X POST http://127.0.0.1:8081/api/entity -H 'Content-Type: application/json' -d '{"action":"reset"}'
```

В `look` координаты `x` и `y` — числа от -1 до 1; положительное `y` означает взгляд вверх. Для `mood` значения `idle`, `happy`, `sad`, `thinking`, `speaking`. Настроение, установленное вручную, может измениться при следующем реальном ответе AI.

Успешный POST возвращает `202 queued`, **не** подтверждение завершения: проверьте новое состояние через `GET /api/status`.

## Безопасные границы

- HTTP слушает только `127.0.0.1`; запросы браузеров с заголовком `Origin` к новому маршруту отклоняются.
- Команды имеют явный белый список полей и значений. Нет выполнения произвольного Python, загрузки модификаций, скриптов, файлов или внешнего сетевого доступа.
- Частые изменения джойстика не записываются на диск: сохраняются лишь форма и скин.
- Существующие маршруты API не переписывались. Текущая локальная альфа в чате не подключена к этому API напрямую.

## Что ещё предстоит

Импорт моделей `.glb` / `.vrm`, привязка костей и мимики к анимациям, преобразование геометрии модели в частицы, синхронизация с чатом и AR. Эти функции **не реализованы** в этой версии.

## Проверки

`./venv/bin/python -m unittest -v tests.test_entity_controller tests.test_face_avatar tests.test_render_resolution`

Тесты проверяют отклонение некорректных команд, сохранение World при смене формы, реальное вращение частиц и отсутствие прямого исполнения API-команды из серверного потока.
